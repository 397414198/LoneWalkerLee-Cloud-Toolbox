# LoneWalkerLee Cloud Toolbox 4.0

🧰 **LoneWalkerLee Cloud Toolbox** 是一个免费、轻量、本地优先的在线工具箱，适合直接部署到 Cloudflare Pages、GitHub Pages 或其他静态托管。

## ✨ 4.0 最终版

- 🧰 950+ 实用工具持续收录
- 🔍 全局搜索 / `Ctrl + K` / `/` 快速唤起
- ⌨️ 搜索结果支持 ↑ ↓ / Enter 键盘操作
- ⭐ 收藏、🕘 最近使用、🔥 高频工具
- 📊 本机使用次数统计，不上传统计数据
- 📤 导出 / 📥 导入个人工具箱配置
- 🧹 一键清理本地配置
- 🌗 深色 / 浅色主题
- 📋 工具弹窗统一“复制结果 / 清空输入”操作
- 📱 移动端适配
- 🔒 本地优先：大多数工具直接在浏览器完成
- 🌐 对依赖第三方服务的工具做明确提示
- 📦 PWA / Service Worker：支持安装到桌面，并提供基础离线壳

## 🔐 隐私说明

收藏、最近使用、主题、使用次数等偏好保存在浏览器 `localStorage` 中。

公网 IP、二维码等需要第三方服务的工具会在界面中提示。请不要把密码、Token、私钥等敏感信息输入到需要第三方服务的工具。

## 🚀 部署

本项目是纯静态前端，无需数据库、服务器或额外 Docker。

Cloudflare Pages 直接连接 GitHub 仓库即可，构建命令留空，输出目录使用项目根目录。

## 📁 核心文件

- `index.html`：页面结构与 PWA 声明
- `style.css`：主题、响应式与最终版 UI
- `app.js`：工具库、交互逻辑与 4.0 增强层
- `manifest.webmanifest`：PWA 配置
- `sw.js`：基础离线缓存

## 🧭 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl/⌘ + K` | 打开全局搜索 |
| `/` | 打开全局搜索（非输入框时） |
| `↑ ↓` | 搜索结果移动 |
| `Enter` | 打开选中的工具 |
| `Esc` | 关闭搜索 / 弹窗 |
| `Ctrl/⌘ + Enter` | 尝试执行当前工具主操作 |
